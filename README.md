## Mock Assessment 02 — Recipe Evaluation System

The project simulates the core of a recipe evaluation system, implemented incrementally across four levels.

---

### 🟢 Level 1 — Recipe Creation and Basic Operations

Level 1 introduces the system core, allowing recipes to be created and basic recipe information to be managed.

> For more implementation details, refer to the [Level 1 Release Notes](./doc/release/release_level_1.md).

---

### 🟡 Level 2 — Recipe Evaluation and Aggregation

Level 2 expands the system with recipe evaluations, introducing ratings, aggregations, ranking, and efficient data processing.

> For more implementation details, refer to the [Level 2 Release Notes](./doc/release/release_level_2.md).

---

### 🟠 Level 3 — Historical Data and Advanced Reports

Level 3 introduces historical evaluations and more complex reporting requirements, requiring efficient queries, ordering, aggregation, and time-based data processing.

> For more implementation details, refer to the [Level 3 Release Notes](./doc/release/release_level_3.md).

---

### 🔵 Level 4 — Concurrency and Scalability

Level 4 hardens the system for a production-like environment, introducing **concurrency safety**, atomic operations, consistency, and scalable processing of recipe evaluations and reports.

> For more implementation details, refer to the [Level 4 Release Notes](./doc/release/release_level_4.md).
